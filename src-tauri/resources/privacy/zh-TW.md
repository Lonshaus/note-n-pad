# 隱私權政策

最後更新：2026 年 8 月 30 日

**Note&Pad 不蒐集任何資料。** 沒有帳號、不需登入、沒有分析、沒有遙測。程式本身不會發出任何網路請求，所以關於你、或關於你寫的內容，都不會離開你的電腦。

## 程式存了什麼、存在哪裡

程式寫出的東西全部留在你自己的機器上：

- **你的檔案**只會從你指定的位置讀寫。程式只開你交給它的東西——透過開啟對話框、拖到視窗上，或從檔案管理員開啟。
- **設定**（主題、介面語言、編碼偏好、視窗狀態）存在程式自己的資料夾裡。
- **便利貼與未儲存變更的快照**也存在同一個地方，這樣意外關機之後內容還在。快照資料夾可以在設定裡改到別處。
- 你建立或匯入的**主題與語言檔**，在那個資料夾裡就是純資料檔。

資料夾位置：

| 平台    | 位置                                                    |
| ------- | ------------------------------------------------------- |
| macOS   | `~/Library/Application Support/net.lonshaus.note-n-pad` |
| Windows | `%APPDATA%\net.lonshaus.note-n-pad`                     |

在 macOS 上，如果程式是從 Mac App Store 安裝的，那個資料夾會改在程式的沙盒容器裡面。

那個資料夾裡的任何東西都不會被傳送出去。刪掉它就等於刪掉全部。

## 網路使用

程式本身不會連上網際網路。

唯一的對外動作是由你發起的：從說明選單選「文件」或「回報問題」，程式會把一個網址交給你的預設瀏覽器。從那一刻起你人在網站上，適用的是該網站自己的隱私權政策。

程式的介面是用系統的網頁檢視元件繪製的（macOS 是 WebKit，Windows 是 WebView2），介面本身只載入隨程式一起安裝的檔案。唯一的例外是 Markdown 預覽：開啟**在預覽中顯示本機資源**之後，它也能顯示你所開啟的那份文件所在資料夾裡的圖片。那些圖片是直接從你的磁碟讀的，不會向外抓取，也讀不到該文件資料夾以外的地方。

## 當機與錯誤資訊

任何東西都不會被送出去。但有一個檔案你應該知道。

程式執行期間會把自己的診斷訊息留在記憶體裡，上限 256 KB，正常運作完全不寫磁碟。程式遇到非預期的失敗時，那份緩衝區會被寫出來，以便查明原因：

| 平台    | 位置                                                         |
| ------- | ------------------------------------------------------------ |
| macOS   | `~/Library/Logs/net.lonshaus.note-n-pad/diagnostic.log`      |
| Windows | `%LOCALAPPDATA%\net.lonshaus.note-n-pad\logs\diagnostic.log` |

注意這不是上面那個資料夾；診斷檔放在系統自己的日誌位置。

這個檔案每次都是整份覆寫，所以不會超過一份緩衝區的大小。它裝的是程式自己的訊息，而那些訊息**可能包含你當時開著的檔案路徑**。它留在你的機器上，除了你不會有別的東西去讀它，你隨時可以刪掉。

另外，你未儲存內容的快照一樣留在你的磁碟上，只用來在下次開啟時把內容還給你。

## 兒童

程式不會把任何人的任何東西送到任何地方，兒童也一樣。失敗時唯一會寫出的就是上面那個診斷檔，而它留在你自己的機器上。

## 你從哪裡取得程式

如果你是從商店安裝 Note&Pad，該商店可能會依照它自己的政策，蒐集關於下載、購買或當機的資訊。那是商店的行為，不是我們的，而且我們不會從中取得任何個人資訊。

## 變更
