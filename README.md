# Note&Pad

English · [正體中文](README.zh-TW.md) · [日本語](README.ja.md)

A lightweight desktop text editor and sticky-notes tool for macOS and Windows.

Built around one goal: open fast, stay reliable, find what you need. Daily notes, code snippets, and huge log files all go through the same tool.

## Key Features

### Tabbed editor

- Syntax highlighting: auto-detects the file's language, or set it manually, covering common programming languages and markup formats
- Find and replace: fast in-file search, replace one at a time or all at once
- Switch line endings (LF/CRLF) and text encoding (UTF-8, UTF-16, Big5, Shift_JIS, and 22 encodings in total) on the fly
- Word wrap and line numbers can each be toggled on or off
- A full menu bar and keyboard shortcuts that match each platform's conventions

### Desktop sticky notes

- Open a new note with one shortcut; content saves as you type
- Three display modes: pinned on top, following a specific app, or a regular window
- Adjustable opacity so a note can sit in a corner without getting in the way
- Jump straight to any sticky note from the Dock/system tray menu

### Workspace

- Browse folders as a tree, double-click to open a file
- Project grouping: files from the same project stay together in one editor window
- A recent-files list for one-step access to files you use often

### Large files

- Files hundreds of MB in size open within seconds
- Viewer mode and windowed editing decouple memory usage from file size, so large files no longer bog down the whole machine
- Jump to line and streaming search work even on large files

### Resilient to accidents

- Unsaved changes are snapshotted automatically; if the app closes unexpectedly or crashes, your content is still there when you reopen it
- Closing a window with unsaved changes triggers a clear confirmation step, so nothing gets discarded silently

### Themes

- 10 built-in color themes, editable in place or saved as your own
- Themes are plain data files: export to share, import from others, and one click to restore if you break one
- Themes only affect the editing area; the window's own appearance follows the system's light or dark mode separately

### Multilingual interface

- 15 interface languages: 正體中文, 简体中文, English, 日本語, 한국어, Deutsch, Français, Español, Português, Русский, Italiano, Polski, Türkçe, ไทย, Tiếng Việt
- Every piece of interface text can be edited and saved as your own language file; you can also import language packs made by others, export your own, and restore the originals at any time
