# Note&Pad

[English](README.md) · [正體中文](README.zh-TW.md) · 日本語

macOSとWindowsに対応した、軽量なデスクトップテキストエディタ兼付箋ツールです。

「すぐ開ける、安心して使える、目的の場所にすぐたどり着ける」ことを目標にしています。日常のメモ、コードの断片、巨大なログファイルまで、同じツールで扱えます。

## 主な機能

### タブ型エディタ

- シンタックスハイライト：ファイルの言語を自動判定、手動指定も可能。主要なプログラミング言語やマークアップ形式に対応
- 検索と置換：ファイル内でのすばやい検索、1件ずつまたは一括での置換
- 改行コード（LF/CRLF）と文字エンコーディング（UTF-8、UTF-16、Big5、Shift_JISなど22種類）をリアルタイムに切り替え
- 折り返し表示・行番号表示のオン/オフ切り替え
- 充実したメニューバーとショートカットキー、各プラットフォームの操作習慣に合わせた挙動

### デスクトップ付箋

- ショートカットキー一つで、その場で開いてすぐ書ける
- 3種類の表示モード：常に最前面にピン留め、指定したアプリケーションに追従、通常ウィンドウ
- 不透明度を調整でき、画面の隅に置いても作業の邪魔にならない
- Dock／システムトレイのメニューから、どの付箋にもすぐアクセス

### ワークスペース

- フォルダをツリー表示し、ダブルクリックでそのまま開ける
- プロジェクトごとのグループ化：同じプロジェクトのファイルを1つの編集ウィンドウにまとめる
- 最近使ったファイルの一覧から、よく使うファイルをワンステップで呼び出せる

### 大容量ファイル

- 数百MBのファイルでも数秒で開ける
- 閲覧モードとウィンドウ化編集：メモリ使用量がファイルサイズに左右されず、大きなファイルでもマシン全体が重くならない
- 行ジャンプやストリーミング検索により、大容量ファイル内でも目的の内容を見つけられる

### 不意のトラブルに強い

- 未保存の変更を自動でスナップショット保存。アプリが不意に終了したりクラッシュしたりしても、再度開けば内容が残っている
- ウィンドウを閉じる際、未保存の内容があれば明確な確認フローが入り、気づかないうちにデータが失われることはない

### テーマ

- 10種類のビルトイン配色を、その場で編集したり、自分のテーマとして別名保存したりできる
- テーマは純粋なデータファイルなので、書き出して共有したり、他人が作ったものを読み込んだりでき、変更に失敗してもワンクリックで元に戻せる
- テーマが影響するのは編集エリアのみ。ウィンドウの外観はシステム設定に従い、ライト／ダークが切り替わる

### 多言語インターフェース

- 15種類のインターフェース言語に対応：正體中文、简体中文、English、日本語、한국어、Deutsch、Français、Español、Português、Русский、Italiano、Polski、Türkçe、ไทย、Tiếng Việt
- インターフェースの文言は1文ずつ自分で編集でき、編集後は言語ファイルとして保存可能。他の人が作った言語パックの読み込みや、自作パックの書き出しもでき、いつでも元の状態に復元できる

## 入手方法

自動アップデートに対応したアプリケーションを、Steamで配信予定です。macOSは13.3以降が必要です。

ソースコードから自分でビルドすることも可能です。手順は [BUILDING.ja.md](BUILDING.ja.md) を参照してください。
